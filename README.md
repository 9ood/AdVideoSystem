# 视频翻拍系统 (AdVideoSystem)

AI 驱动的视频分析与脚本生成系统,自动将视频拆解为 Sora 可执行的脚本

## ✨ 核心功能

- 🎬 **自动镜头检测** - 智能识别视频中的场景切换
- 🖼️ **关键帧提取** - 自动提取每个镜头的关键画面
- 🤖 **AI 智能分析** - 使用 Gemini 3 Flash 生成专业的 Sora 提示词
- 📊 **三种脚本输出**:
  - **全局信息** - 视频整体概况和参数设置
  - **详细镜头脚本** - 每个镜头的完整提示词和台词
  - **浓缩脚本** - 10-15秒精华版,保留核心故事和情感
- 🌐 **Web 界面** - 简单易用的网页操作界面
- 📦 **一键导出** - Excel 表格 + 关键帧图片打包下载

## 🎯 输出说明

系统会生成一个包含 **3 个工作表** 的 Excel 文件:

1. **全局信息** - 视频总时长、镜头数量、整体风格建议
2. **镜头详情** - 每个镜头的时间、类型、完整 Sora 提示词、台词
3. **浓缩脚本** - 将整个视频浓缩为 10-15 秒的精华版本,包含:
   - 建议时长
   - 核心故事提炼
   - 完整 Sora 提示词(包含台词)
   - 保留的关键场景

## 🛠️ 技术栈

- Python 3.8+
- Flask (Web 框架)
- PySceneDetect (镜头检测)
- FFmpeg (视频处理)
- OpenRouter + Gemini 3 Flash (AI 分析)
- openpyxl (Excel 生成)

## 📦 安装

```bash
pip install -r requirements.txt
```

## ⚙️ 配置

创建 `.env` 文件并添加你的 API 密钥:

```
OPENROUTER_API_KEY=your_api_key_here
```

## 🚀 运行

### 本地运行

```bash
python app.py
```

然后访问 http://localhost:8080

### 公网访问

如果需要让其他人通过网络访问:

1. 安装 ngrok: https://ngrok.com/download
2. 启动系统后,在新终端运行:
   ```bash
   ngrok http 8080
   ```
3. 将生成的公网地址(如 `https://xxxxx.ngrok-free.dev`)分享给他人

## 📖 使用流程

1. 打开网页界面
2. 上传视频文件(支持 MP4、AVI、MOV 等格式)
3. 点击"开始处理"
4. 等待处理完成(视频越长,处理时间越长)
5. 下载生成的 Excel 文件和关键帧图片

## 💡 特色功能

- ✅ **中文优化** - 所有提示词自动适配中国角色和场景
- ✅ **台词生成** - 自动为口播类视频生成中文台词
- ✅ **完整提示词** - 包含所有参数,可直接用于 Sora 生成视频
- ✅ **浓缩脚本** - 智能提炼核心故事,生成精华版本
